HOSPITAL MANAGEMENT SYSTEM - STREAMLIT

RUN IN VS CODE:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: python -m pip install -r requirements.txt
5. Run: python -m streamlit run app.py
6. Open the local URL shown in the terminal (usually http://localhost:8501).

FEATURES:
Dashboard, patient management, doctor management, appointments, medical records,
billing, pharmacy stock, reports, JSON and CSV downloads. Data is saved locally
in hospital_data/*.json.

NOTE: This is a student demo, not a production-ready medical system. It has no
login, role permissions, encrypted storage, backups, or compliance controls.
Do not use real patient information.
